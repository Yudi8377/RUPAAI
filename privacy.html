Kebijakan Privasi

Informasi tentang data yang diproses ketika Anda menggunakan pratinjau gaya rambut RUPAAI.

Terakhir diperbarui: 19 Oktober 2026

Ringkasnya: fitur kamera dan pewarnaan rambut saat ini memproses gambar di browser pada perangkat Anda. Fitur ini tidak mengunggah frame kamera ke server RUPAAI. Jangan gunakan layanan ini untuk memasukkan informasi pribadi orang lain tanpa izin mereka.

1. Data yang diproses

  • Video kamera: hanya diakses setelah Anda menekan tombol untuk mengaktifkan kamera dan menyetujui izin browser. Frame diproses di perangkat untuk membuat pratinjau warna rambut.
  • Gambar yang disimpan: tombol “Simpan frame” membuat file PNG melalui browser dan memulai unduhan ke perangkat Anda. RUPAAI tidak menerima salinan file tersebut melalui fitur ini.
  • Pilihan tampilan: pilihan warna, referensi potongan, dan favorit hanya berada dalam sesi halaman saat ini; fitur prototipe ini tidak menyimpan riwayat akun.
  • Data server: situs dapat menerima data teknis standar yang diperlukan oleh penyedia hosting untuk mengirimkan halaman. RUPAAI saat ini tidak menyediakan akun pengguna atau penyimpanan foto berbasis server.

2. Model AI dan layanan pihak ketiga

Untuk menjalankan segmentasi rambut, browser mengunduh kode runtime dan model AI dari CDN publik seperti jsDelivr atau unpkg serta penyimpanan model Google MediaPipe. Permintaan tersebut dapat mengungkapkan informasi teknis jaringan kepada penyedia terkait sesuai kebijakan mereka. Jika model gagal dimuat, pratinjau kamera dapat tetap aktif tanpa efek segmentasi rambut.

3. Izin kamera dan kontrol Anda

Anda dapat menolak izin kamera, mematikan kamera melalui kontrol di halaman, atau mencabut izin dari pengaturan browser. Menutup atau menyegarkan halaman akan mengakhiri sesi kamera. Jika Anda tidak ingin menggunakan kamera, jangan aktifkan fitur tersebut.

4. Anak-anak dan foto orang lain

Gunakan layanan ini hanya jika Anda berhak menggunakan gambar yang ditampilkan dan telah memperoleh izin yang diperlukan. Orang tua atau wali perlu mendampingi anak saat menggunakan kamera.

5. Keamanan dan perubahan

Kami berupaya menjaga pengalaman ini sederhana dan memproses pratinjau secara lokal, tetapi tidak ada sistem yang dapat dijamin bebas risiko. Jangan mengandalkan prototipe ini untuk data yang sangat sensitif. Kebijakan ini dapat diperbarui saat fitur dan cara pemrosesan data berubah.

6. Kontak

RUPAAI belum menampilkan kanal dukungan pelanggan terverifikasi pada prototipe ini. Jangan mengirimkan data sensitif melalui kanal yang belum dikonfirmasi sebagai kanal resmi.
